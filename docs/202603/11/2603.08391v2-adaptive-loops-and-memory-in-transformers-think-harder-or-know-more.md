## 摘要
思维链（CoT）提示使语言模型能够进行推理，但需要对中间步骤进行显式的文本化表达。循环 Transformer（Looped transformers）通过在隐藏状态内迭代优化表示，提供了一种替代方案。这种参数效率是以牺牲性能为代价的，因为循环模型缺乏更深层模型所具有的存储容量，后者在每一层都使用唯一的权重。在这项工作中，我们研究了同时具备逐层自适应循环（其中每个 Transformer 块通过学习到的停机机制来学习迭代其隐藏状态）和门控记忆库（提供额外的学习存储）的 Transformer 模型。我们发现，与参数量和 FLOPs 匹配的模型相比，循环主要有利于数学推理，而记忆库则有助于恢复在常识任务上的性能。结合这两种机制所产生的模型在数学基准测试中优于层数是其三倍的等 FLOPs 基准模型。对模型内部的分析揭示了层的专业化：早期层学习进行极少的循环并谨慎地访问记忆，而后期层则更频繁地进行这两项操作。

## Abstract
Chain-of-thought (CoT) prompting enables reasoning in language models but requires explicit verbalization of intermediate steps. Looped transformers offer an alternative by iteratively refining representations within hidden states. This parameter efficiency comes at a cost, as looped models lack the storage capacity of deeper models which use unique weights per layer. In this work, we investigate transformer models that feature both adaptive per-layer looping, where each transformer block learns to iterate its hidden state via a learned halting mechanism, and gated memory banks, that provide additional learned storage. We find that looping primarily benefits mathematical reasoning, while memory banks help recover performance on commonsense tasks compared to parameter and FLOP matched models. Combining both mechanisms yields a model that outperforms an iso-FLOP baseline, with three times the number of layers, across math benchmarks. Analysis of model internals reveals layer specialization: early layers learn to loop minimally and access memory sparingly, while later layers do both more heavily.

*   **核心问题**：模型应该通过“更努力地思考”（增加循环迭代）还是“知道得更多”（增加存储容量）来提升表现？论文探讨了将**自适应循环机制**与**外部记忆库**结合，是否能同时解决推理深度和知识容量的问题。

### 2. 方法论
论文提出了一种增强型 Transformer 架构，包含两个核心组件：
*   **自适应循环（Adaptive Looping）**：
    *   借鉴 PonderNet 的思想，为每个 Transformer 块引入一个**停机路由器（Halting Router）**。
    *   模型在每一层可以自主决定迭代次数（最高 $N_{max}$ 次）。
    *   最终输出是各次迭代结果的加权组合，权重由停机概率 $p_t$ 决定。
    *   引入了**可学习的循环缩放参数**（$\alpha_t$），初始值设为接近恒等映射，以确保训练初期的稳定性。
*   **门控记忆库（Gated Memory Banks）**：
    *   **局部记忆**：每一层拥有独立的 Key-Value 存储空间，用于存放层特定的知识。
    *   **全局记忆**：所有层共享一个存储空间，用于存放通用知识。
    *   **门控集成**：使用输入相关的门控标量（Gating）来控制从记忆库中检索到的信息如何融入残差流，避免强制使用记忆干扰正常计算。

### 6. 主要结论与发现
*   **功能解耦**：循环机制主要提升**数学推理**（算法化计算），而对常识任务帮助较小；记忆库则能显著恢复模型在**常识任务**上的表现。
*   **层间专业化**：模型内部出现了明显的层级分工。**早期层**倾向于极少循环且很少访问记忆；**后期层**则表现出密集的循环和频繁的记忆检索。
*   **性能优势**：结合了循环与记忆的模型，在数学基准上的表现优于层数多出三倍的 Iso-FLOP 基准模型。

### 7. 优点
*   **架构创新**：巧妙地结合了隐式思考（循环）与显式存储（记忆库），为解决循环 Transformer 的容量瓶颈提供了新方案。
*   **效率提升**：证明了在特定任务（如数学）上，通过循环增加“深度”比单纯堆叠物理层更具参数效率。
*   **深入的内部分析**：通过可视化停机概率和门控值，揭示了模型如何自发学习“何时思考”以及“何时查阅知识”。

### 8. 不足与局限
*   **评估指标限制**：数学任务使用了 BPB（负对数似然的变体）而非直接的答案准确率，这可能无法完全反映模型解决复杂多步推理问题的最终能力。
*   **规模风险**：在 200M 参数量级得出的结论是否能平移至超大规模模型仍存疑，因为大模型本身可能已具备足够的冗余参数来存储知识。
*   **推理延迟**：虽然参数高效，但循环机制在推理时仍需多次迭代，对于实时性要求极高的场景可能存在限制。
