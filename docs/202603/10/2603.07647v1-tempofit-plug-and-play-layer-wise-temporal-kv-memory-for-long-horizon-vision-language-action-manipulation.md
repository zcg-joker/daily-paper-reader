## 摘要
预训练的视觉-语言-动作（VLA）策略在单步操纵方面已取得显著成果，但其推理过程在很大程度上仍是无记忆的，这在存在遮挡、状态混淆和细微动作后变化的非马尔可夫长程设置中表现得非常脆弱。先前的方法要么通过堆叠帧来注入历史信息，这会增加视觉 token 数量和延迟，同时引入近乎重复的像素；要么通过学习额外的时间接口，这需要（重新）训练，并可能破坏原始的单帧推理图。我们提出了 TempoFit，这是一种无需训练的时间改造方案，通过状态级记忆升级冻结的 VLA。我们的核心见解是，前缀注意力 K/V 已经形成了一种模型原生的、可内容寻址的运行时状态；跨时间步重用它们可以在不增加新 token 或可训练模块的情况下引入历史信息。TempoFit 在选定的中间层存储逐层 FIFO 前缀 K/V，利用受 NLP 中位置偏差启发的固定近期偏差——帧间隙时间偏差（FGTB）执行无参数的 K-to-K 检索，以保持决策以当前为主导，并通过带有保范数重缩放的注意力前残差加载注入检索到的上下文，从而避免冻结权重下的分布偏移。在 LIBERO-LONG 上，TempoFit 将强大的预训练骨干网络的平均成功率提高了多达 4.0%，同时保持了近乎实时的延迟，并能一致地迁移到 CALVIN 和真实机器人长程任务中。

## Abstract
Pretrained Vision-Language-Action (VLA) policies have achieved strong single-step manipulation, but their inference remains largely memoryless, which is brittle in non-Markovian long-horizon settings with occlusion, state aliasing, and subtle post-action changes. Prior approaches inject history either by stacking frames, which scales visual tokens and latency while adding near-duplicate pixels, or by learning additional temporal interfaces that require (re-)training and may break the original single-frame inference graph. We present TempoFit, a training-free temporal retrofit that upgrades frozen VLAs through state-level memory. Our key insight is that prefix attention K/V already form a model-native, content-addressable runtime state; reusing them across timesteps introduces history without new tokens or trainable modules. TempoFit stores layer-wise FIFO prefix K/V at selected intermediate layers, performs parameter-free K-to-K retrieval with Frame-Gap Temporal Bias (FGTB), a fixed recency bias inspired by positional biases in NLP, to keep decisions present-dominant, and injects the retrieved context via pre-attention residual loading with norm-preserving rescaling to avoid distribution shift under frozen weights. On LIBERO-LONG, TempoFit improves strong pretrained backbones by up to +4.0% average success rate while maintaining near-real-time latency, and it transfers consistently to CALVIN and real-robot long-horizon tasks.

### 1. 核心问题与整体含义
*   **研究动机**：当前的视觉-语言-动作（VLA）模型虽然在单步操作上表现强劲，但大多遵循“无记忆”的单帧决策范式。在长程（Long-horizon）任务中，由于缺乏对历史的感知，模型在面对**遮挡、状态混淆（如两个相似物体）以及动作后细微环境变化**时非常脆弱，容易出现重复操作或步骤中断。
*   **核心挑战**：现有的引入历史信息的方法存在缺陷：
    1.  **帧堆叠（Frame Stacking）**：显著增加视觉 Token 数量，导致推理延迟激增，且引入大量冗余像素。
    2.  **额外训练接口**：需要重新训练或微调模型，破坏了原始预训练模型的推理图，难以实现“即插即用”。
*   **整体含义**：TempoFit 旨在提供一种**无需训练、即插即用**的方案，通过复用模型内部原生的注意力机制状态（KV Cache）来赋予冻结的 VLA 模型长程记忆能力。

### 2. 方法论
TempoFit 的核心思想是将 Transformer 内部的 Key/Value (K/V) 状态视为一种内容寻址的记忆库。
*   **逐层 FIFO KV 缓存**：在 VLA 骨干网络的选定中间层（而非所有层）维护一个先进先出（FIFO）的缓冲区，存储过去 $C$ 帧的前缀 K/V 状态。
*   **K-to-K 检索（核心技术）**：
    *   利用当前帧的 Key 作为查询向量，与历史 Key 进行相似度匹配。
    *   这种“键对键”的匹配方式不改变原始模型的注意力几何结构，比传统的“查询对键（Q-to-K）”在冻结权重下更稳定。
*   **帧间隙时间偏差（FGTB）**：
    *   借鉴 NLP 中的位置偏差（如 ALiBi），在检索分值上施加一个随时间间隔增加而增大的负偏差。
    *   **作用**：强制模型保持“当前主导”，抑制过时的历史干扰，确保决策的实时相关性。
*   **保范数残差加载（Norm-Preserving Residual Loading）**：
    *   将检索到的历史上下文通过残差方式注入当前 KV 状态。
    *   为了防止数值爆炸或分布偏移，对融合后的张量进行重缩放，使其保持原始的 $\ell_2$ 范数，确保后续冻结层能正常处理。

### 3. 实验设计
*   **数据集与场景**：
    1.  **LIBERO-LONG**：包含 10 个复杂的多阶段操纵任务。
    2.  **CALVIN**：评估连续指令执行能力，包括 D-D（同环境）和 ABC-D（跨环境泛化）设置。
    3.  **真实机器人**：使用 Realman RM-65B 机械臂执行 3 个长程任务（如清理桌面、按序摆放物体）。
*   **基准模型（Backbones）**：采用了强大的预训练模型 $\pi_{0.5}$ 和 QwenGR00T。
*   **对比方法**：包括 SOTA 的训练型时间模型（如 MemoryVLA, HiF-VLA）以及多种消融变体。

### 4. 资源与算力
*   **训练算力**：**无需训练**。该方法是纯推理侧的改造，不涉及参数更新。
*   **推理算力**：实验在 **NVIDIA RTX 5090 GPU** 上进行。
*   **效率表现**：在缓存 8 帧历史的情况下，推理延迟仅从 71.2ms 增加到 74.4ms（增幅约 4%），而传统的帧堆叠方法延迟会翻倍（达到 176.3ms）。

### 5. 实验数量与充分性
*   **实验规模**：
    *   在 LIBERO-LONG 上进行了 **500 次试验**（10 个任务 $\times$ 50 次），样本量充足。
    *   在 CALVIN 上评估了 5 个连续指令的平均成功长度。
    *   真实机器人实验包含 3 个任务，每个任务 20 次试验。
*   **消融实验**：非常详尽，涵盖了组件贡献（KV 记忆 vs FGTB）、检索策略（Q-to-K vs K-to-K）、注入策略（连接 vs 残差）、层选择（顶层/底层/中间层）以及缓存容量 $C$ 的影响。
*   **客观性**：通过在不同架构（基于不同 LLM 的 VLA）上验证，证明了方法的通用性；对比了最新的 SOTA 模型，结果具有说服力。

### 6. 主要结论与发现
*   **性能提升**：在 LIBERO-LONG 上，TempoFit 将 $\pi_{0.5}$ 的成功率从 92.6% 提升至 **96.6%**，将 QwenGR00T 从 90.8% 提升至 **94.4%**。
*   **长程优势**：在 CALVIN 实验中，TempoFit 的优势主要体现在第 3 到第 5 条连续指令上，证明其有效缓解了长程执行中的“遗忘”和“断档”问题。
*   **层级敏感性**：发现**中间层**最适合存储记忆。底层特征太原始，顶层特征太趋向于预训练目标，中间层特征最具迁移性和组合性。
*   **实时性**：证明了状态级记忆比观察级记忆（帧堆叠）在计算开销上具有压倒性优势。

### 7. 优点
*   **极简集成**：无需修改模型权重，无需重新训练，几行代码即可升级现有 VLA。
*   **高效性**：不增加输入 Token 长度，内存和计算开销极小，适合闭环实时控制。
*   **鲁棒性**：通过 FGTB 和保范数技术，解决了冻结权重下引入历史信息导致的分布偏移问题。

### 8. 不足与局限
*   **超参数依赖**：层选择（$L_{mem}$）、缓存容量（$C$）和衰减斜率（$\beta$）目前仍需手动指定或根据经验选择，缺乏自动适配机制。
*   **记忆深度限制**：虽然提升了长程表现，但对于需要极长时间跨度（如数分钟前的信息）的复杂推理，FIFO 缓存可能仍显不足。
*   **任务覆盖**：虽然在操纵任务上表现良好，但在需要高频动态调整或极高精度视觉反馈的任务中，历史记忆的引入是否会产生负面“拖影”效应尚待进一步研究。
