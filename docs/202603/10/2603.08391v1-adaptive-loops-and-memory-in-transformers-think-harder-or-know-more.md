## 摘要
思维链（CoT）提示使语言模型能够进行推理，但需要对中间步骤进行显式的文本化表达。循环 Transformer（Looped transformers）通过在隐藏状态内迭代优化表示，提供了一种替代方案。这种参数效率是以牺牲性能为代价的，因为循环模型缺乏更深层模型所具有的存储容量，后者在每一层都使用唯一的权重。在这项工作中，我们研究了同时具备逐层自适应循环（每个 Transformer 块通过学习到的停机机制来学习迭代其隐藏状态）和门控记忆库（提供额外的学习存储）的 Transformer 模型。我们发现，与参数量和 FLOPs 匹配的模型相比，循环主要有利于数学推理，而记忆库则有助于恢复在常识任务上的性能。结合这两种机制所产生的模型在数学基准测试中优于等效 FLOPs 的基准模型（该基准模型的层数是前者的三倍）。对模型内部的分析揭示了层的专业化：早期层学习进行极少的循环并谨慎地访问记忆，而后期层则更频繁地进行这两项操作。

## Abstract
Chain-of-thought (CoT) prompting enables reasoning in language models but requires explicit verbalization of intermediate steps. Looped transformers offer an alternative by iteratively refining representations within hidden states. This parameter efficiency comes at a cost, as looped models lack the storage capacity of deeper models which use unique weights per layer. In this work, we investigate transformer models that feature both adaptive per-layer looping, where each transformer block learns to iterate its hidden state via a learned halting mechanism, and gated memory banks, that provide additional learned storage. We find that looping primarily benefits mathematical reasoning, while memory banks help recover performance on commonsense tasks compared to parameter and FLOP matched models. Combining both mechanisms yields a model that outperforms an iso-FLOP baseline -- with three times the number of layers -- on math benchmarks. Analysis of model internals reveals layer specialization: early layers learn to loop minimally and access memory sparingly, while later layers do both more heavily.

*   **背景**：思维链（CoT）通过显式文本步骤增强推理，但效率较低。循环 Transformer（Looped Transformers）通过在隐藏状态内多次迭代同一层权重来实现“隐式推理”，虽然参数效率高，但由于缺乏深层模型的独特权重，其存储知识的能力（容量）受限。
*   **核心问题**：能否通过结合“自适应循环”和“外部记忆库”，让模型既能通过多次迭代“努力思考”（推理），又能通过记忆库“博闻强识”（存储知识）？

### 2. 论文提出的方法论
作者提出了一种增强型架构，包含两个核心组件：
*   **自适应循环（Adaptive Looping）**：
    *   借鉴 PonderNet 的思想，每个 Transformer 块可以迭代运行最多 $N_{max}$ 次。
    *   引入**学习停止机制（Halting Mechanism）**：一个路由器预测每一步的停止概率 $p_t$，最终输出是所有迭代步骤状态的加权组合。
    *   **可学习缩放参数**：为保证训练初期稳定，循环路径初始接近恒等映射，随后逐渐学习介入。
*   **门控记忆库（Gated Memory Banks）**：
    *   **局部记忆（Local Memory）**：每一层拥有独立的 Key-Value 存储槽，用于存储层特定的知识。
    *   **全局记忆（Global Memory）**：所有层共享的存储槽，用于存储通用知识。
    *   **门控集成**：使用输入相关的门控机制（Gating）来决定何时从记忆库中提取信息，避免强制使用记忆干扰正常计算。

### 6. 主要结论与发现
*   **功能解耦**：**循环机制**主要提升数学推理能力（算法化计算），而对常识任务帮助较小；**记忆库**则能显著恢复因参数共享而损失的常识表现。
*   **超越深层模型**：在数学基准上，结合了循环和记忆的模型优于层数多出三倍的 Iso-FLOP 基准模型。
*   **层级专业化**：模型自动学习到分工——**早期层**循环极少且几乎不访问记忆；**后期层**则频繁循环并大量调用记忆库。
*   **阶段性演进**：模型并非从训练开始就使用循环，而是在验证集交叉熵损失降至约 3.27 之后（即具备一定语言能力后），才开始爆发式地利用循环机制。

*   **架构优雅**：将“计算深度”与“存储容量”解耦，为解决 Transformer 参数冗余提供了新思路。
*   **自发涌现**：层级专业化和循环的“相位转换”是在没有显式惩罚（Ponder Penalty）的情况下，仅通过优化预测损失自发产生的。
*   **参数效率**：证明了在特定任务（如数学）上，循环比单纯堆叠层数更具参数效率。

### 8. 不足与局限
